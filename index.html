① 品类自定义（JSON 驱动）

商家提交 JSON 文本声明品类树与属性 Schema，系统执行「语法校验 → 结构语义校验 → 建树 → 衍生生成 → 落库」五步处理，自动产出属性 Schema、动态商品发布表单、检索索引映射与 AI 提示词上下文片段。新增品类无需发版。

查看图 3-6 / 4-9

② 智能客服（RAG + 工具调用）

以意图分流为核心设计：知识咨询型问题走向量检索增强生成，业务事实型问题走受控工具调用获取真实数据；答复经安全护栏过滤后以流式返回，置信度不足时携带会话摘要转接人工。

查看图 3-4 / 4-11

③ 智能选品（多路召回 + 精排）

画像构建 → 多路并行召回（协同过滤 / 向量语义 / 热门新品）→ 精排打分 → 业务规则过滤 → 多样性重排 → 冷启动兜底，行为埋点回流形成自增强闭环。

查看图 3-7 / 4-12

④ 智能组货（可售性优先）

把「会推荐」升级为「能成交」：大模型只生成搭配理由，候选商品的库存、履约、价格与毛利全部由业务服务计算校验，只有四维同时成立的组合才会输出，否则降级为单品推荐。

查看图 3-8 / 4-13

⑤ 分层架构 + AI 能力中台

表现层、应用层、领域层、智能能力层、基础设施层单向依赖并配合依赖倒置；三项 AI 能力共享模型网关、向量检索、提示词管理与安全护栏，模型与算法组件均可通过配置替换。

查看图 4-1 / 4-4 / 4-5

⑥ 可降级、可观测、可追溯

AI 异常不阻断交易主流程，所有 AI 接口在响应中显式返回降级标记；全链路追踪贯通业务与模型调用，记录 token 消耗与护栏命中；需求—用例—UML 图—设计章节建立双向追踪矩阵。
